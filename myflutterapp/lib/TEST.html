※ 해당 형번의 투명 청색은 재료 특성상 다른 튜브 종류에 비해 투명도가 없는 편입니다.
높은 투명도를 원하시는 경우, 다른 형번의 투명 튜브 이용 부탁 드립니다.


일반 배관 스트레이트 소프트 나일론 튜브의 사양

사용 유체：공기, 물（조건 있음※1, 2）, 열매체유（조건 있음※3）
최고 사용 압력（20℃ 65%RH일 때）：1.0MPa※4
사용 진공 압력：-100kPa
사용 온도 범위：-15～+90℃（동결되지 않을 것）
튜브 컬러：12색
（경고）

  •  
  • ※ 1. 물, 열매체유 사용 시에는 서지 압력을 최고 사용 압력 이하로 억제하여 사용해 주십시오.
  •  
  • ※ 2. 일반 수돗물은 사용할 수 있습니다. 기타의 물을 사용하는 경우는 문의해 주십시오.
  •  
  • ※ 3. 원터치 조인트에 접속하여 물, 열매체유를 사용할 때는 반드시 인서트 링을 사용해 주십시오.
  •  
  • ※ 4. 최고 사용 압력는 20℃ 65%RH일 때의 값입니다. 기타 온도의 경우는 파괴 압력 곡선에서 충분히 여유가 있는 안전률을 보고 사용해 주십시오.
  •
